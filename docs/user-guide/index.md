# 知识工作工具箱

一个入口，五个动作：找文档、看全库、对账、立契约、记案卷。

```bash
python3 examples/kit/kit.py <动作> [参数]      # 想短一点，可把它软链成 kg
```

## 找一份文档

```bash
$ kg find 材料
[规格] docs/specification/piece/material.md
$ kg find journal
[产物] data/journal
[案例] docs/gallery/artifacts/journal.md
```

按名字找，同时认**文件名**和**篇内标题**——因为体系规定文件名用英文、标题用中文，两者不互译。找不到就模糊兜一层（`日志规范` 会落到 `日志`）。

## 看全库

```bash
$ kg list                # 按资产种类列出全部条目
$ kg list --json 目录.json   # 导出目录（其他程序可读）
```

## 对账

```bash
$ kg check
对账通过：二十格齐备，无未登记目录。
```

两个方向一起查：**契约有而仓库没有**（缺资产）、**仓库有而契约没有**（未登记）。后者尤其有用——新目录出现时它会自己冒出来，提示你「这个还没登记」。

## 立一份契约

开工前把要什么写清楚，做完照着核对：

```bash
$ kg new-contract 契约.md      # 写出骨架
$ kg audit-contract 契约.md    # 核对四段是否齐全
  ✓ 目标   ✓ 输出形态   ✓ 必须包含   ✓ 检查项
契约完整。
```

契约的四段是：**目标**（要什么）、**输出形态**（交付成什么样）、**必须包含**（不能漏的要素）、**检查项**。检查项分两类——能写成断言的**机械核对**（交给程序或 CI），只能人看的**闸门项**（留给验收拍板）。

## 记一次案卷

一件交付做完，把过程记下来：

```bash
$ kg audit-dossier 案卷.md     # 核对五段是否齐全
  ✓ 生成者产出   ✓ 审查者报告   ✓ 人类裁决   ✓ 最终成果
案卷完整。
```

案卷的价值在过程：谁按什么做的、核对了什么、谁拍的板、最后交出什么。少一段就自查不过。

## 这套工具取舍了什么

**留下的**是动作——五个都能在仓库上直接跑，不需要启动任何服务，也不需要数据库。

**砍掉的**是三样：

- **四份验证脚本里的样本数据**——样本是用来验证结构的，结构立住之后样本就是负担；
- **一次性验证**（材料字段那条）——结论已经拿到（四字段够用、阶段由位置承担），不需要常驻一个命令；
- **服务端与数据库**——从第一份碎片到最后一个动作，没有一处需要它：文档在文件里，索引现扫现生成。

**合并方式**：契约与目录两层的库直接复用（`examples/resolver/`），工具只做入口，不复制代码——一份事实源。

## 边界

- **只读仓库，不改内容**——找、看、对账都不动文件；写入仍由人和 AI 在对话里做，提交仍走 git；
- **不是服务**——没有端点、没有数据库、没有后台进程；
- **认名字与位置**——名字（文件名 + 中文标题）管找到，位置（资产与落点规则）管归属；这两样是地基，工具只是把地基用起来。
